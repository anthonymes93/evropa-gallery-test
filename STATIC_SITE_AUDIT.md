# Evropa Flooring independent-static-site audit

## Requirement
The Vercel deployment must never depend on evropaflooring.com for images, scripts, styles, fonts, AJAX responses, gallery assets, or other runtime resources. Third-party Google Maps and Google Fonts are a separate dependency category, not the original WordPress host.

## Confirmed repairs in this branch
- Repointed four Elementor hero slideshow image entries to existing local photo-gallery images.
- Matched 30 missing Projects gallery thumbnail references to unique existing local image files.
- Repaired broken logo and decorative-image asset references.
- Removed invalid responsive image source lists where files were missing.
- Normalized doubled slash paths generated by reference replacements.
- Preserved the functioning locally hosted Swiper script.
